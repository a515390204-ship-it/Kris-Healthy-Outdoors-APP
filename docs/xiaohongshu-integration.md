# 小红书接入知识库说明

## 当前结论

小红书适合作为知识库的补充信息源，但现阶段更建议作为：

- 灵感来源
- 用户真实体验来源
- 路线评价与踩坑补充来源

不建议把它直接当作唯一事实源。

## 推荐接入方式

优先级从高到低：

1. 人工导入
2. 半自动导入
3. 未来再评估平台官方能力或授权合作能力

## 为什么先不用“全自动抓取”

- 当前公开开放平台能力更偏商品、订单、库存、物流等业务接口
- 没有明确、稳定、通用的公开“笔记内容检索/批量同步”接口可直接用于知识库建设
- 如果直接依赖非公开抓取链路，稳定性、合规性和维护成本都比较差

## 推荐的数据流

1. 运营或编辑筛选小红书链接
2. 人工确认主题、标签、摘要、适用场景
3. 写入统一内容模型
4. 用官方信息或景区信息校验路线、开放时间、安全事项
5. 以站内内容形式对外展示

## 在你的产品里最适合承载的字段

- 标题
- 摘要
- 标签
- 场景关键词
- 用户体感评价
- 图片引用
- 原始链接
- 可信度等级

## 建议角色分工

- 小红书：补充真实体验与用户语言
- 官方文旅/景区：提供路线事实与公告
- 站内编辑：形成最终可消费的攻略卡片、问答和专题页
