# 90_Scripts

Automation layer for the v2 knowledge architecture.

Planned script groups:

- `ingest/`: import raw source material.
- `normalize/`: resolve place identity, aliases, and external IDs.
- `update_cards/`: apply accepted claims to cards field by field.
- `validate/`: check schema, relations, wikilinks, freshness, and conflicts.
- `export/`: generate views and app-facing datasets.
