# 10_Mutable

Working layer for evidence extraction, structured claims, drafts, conflicts, and review queues.

- `Evidence/`: smallest source-backed fragments.
- `Claims/`: structured assertions extracted from evidence.
- `Draft_Cards/`: cards being assembled or revised.
- `Review_Queue/`: items needing human or trusted-source review.
- `Conflicts/`: explicit conflict records.

This layer may change frequently. It is where new sources become usable knowledge.
