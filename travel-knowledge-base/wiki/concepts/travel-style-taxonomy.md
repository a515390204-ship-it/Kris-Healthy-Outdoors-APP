# Travel style taxonomy

## Styles

- Check-in: landmarks, photo spots, iconic routes.
- Food: restaurants, markets, local specialties, cafes.
- Culture/history: museums, heritage, architecture, older districts.
- City Walk: walkable neighborhoods and street-level routes.
- Relaxed vacation: hotels, resort rhythm, lower density days.
- Intense: dense multi-point days, early starts, transit efficiency.

## Usage

Each recommendation should explicitly state which style it fits and which style it does not fit.
