# Source confidence model

## Confidence Levels

- `draft`: one unverified source, usually Xiaohongshu or manual note.
- `mixed`: multiple independent user sources align.
- `verified`: checked against official tourism, attraction, map, transport, or hotel source.
- `needs_verification`: cannot be used directly in a final itinerary.

## Xiaohongshu Handling

Use Xiaohongshu for experience evidence, not final factual authority.
